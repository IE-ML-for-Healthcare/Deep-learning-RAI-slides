# Template Improvements

Candidate log for improvements discovered while building a course that may benefit the reusable IE SciTech Reveal.js template. In the template itself this file stays empty; each course repository fills its own copy.

- This is a candidate log, not approval to port
- Course-specific content is never recorded as reusable
- The professor decides whether a candidate is ported
- Porting happens in the template repository, following `instructions/port_back_template_improvements.md`

## Status values

- Candidate
- Approved for port-back
- Rejected
