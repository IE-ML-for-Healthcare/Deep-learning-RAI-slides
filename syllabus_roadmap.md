## 1. Document purpose and boundaries

This roadmap defines the course content, learning sequence, activities, minimum viable outcomes, feedback loops, risks, and fallbacks. It is an agile working plan: slides, timing, tools, and materials are designed and approved package by package.

This roadmap does not authorise an AI assistant to:

- Change assessment weights, or invent grading rules, tests, or rubrics
- Invent requirements, logic, integrations, or architecture for a reference project
- Require paid tools, live personal data, credentials, or personal accounts without approval
- Replace real user evidence with synthetic users or AI-generated feedback
- Change the session order or course objectives without professor approval
